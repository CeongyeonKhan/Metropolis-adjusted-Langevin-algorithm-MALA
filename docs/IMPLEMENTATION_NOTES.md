# 实现与文档公式的对应关系

## 接受目标与提议梯度

解析目标的 `GaussianMixtureTarget.energy` 是唯一接受能量。`GradientEnsemble` 的集成均值只进入局部候选均值；即使其梯度场存在误差，校正后的局部核仍以解析目标为不变分布。

## 状态相关局部核

`StepController.evaluate` 返回当前位置的全部冻结参数。`run_sampler` 生成候选点后，对所有数值有效的候选点再次调用控制器，再由 `isotropic_log_proposal` 分别计算正向与反向高斯密度。拒绝时复用当前状态缓存；接受局部候选时缓存候选状态；接受全局候选时使缓存失效。

## 白化与原始坐标诊断

正式采样默认在预热阶段固定的白化坐标中执行。每个检查点先把当前链状态逆变换到原始坐标，再计算 `distribution/fid_raw`；参考带也直接从原始目标抽样得到。样本制品同时保存工作坐标和原始坐标，避免把白化空间指标误标为原始空间指标。

## 误差约束

`GradientEnsemble.disagreement_variance` 的分母为 $\(J(J-1)\)$，对应集成均值方差代理。`ErrorCalibrator` 采用三划分与有限样本比值分位数，避免把“残差分位数乘预测值”这一未闭合表述直接写入代码。

## 曲率约束

保守傅里叶误差使用解析海森矩阵；正交误差使用一般雅可比。低维精确模式取最大奇异值；高维幂迭代模式使用固定探针和固定轮数的海森矩阵—向量积，并按实际乘积次数计入等效成本。非保守正交误差自动保留精确奇异值路径。边界增强误差暂将边界倍率视为冻结的逐点局部倍率，没有把该结果称为严格上界。

## 全局核

`GlobalMixtureProposal.log_prob` 对所有高斯和学生 $\(t\)$ 分量执行对数求和指数计算，接受率使用完整混合密度，而不是实际抽中分量的密度。路由概率在所有状态上固定。

## 独立拟合参考分布

默认 `reference.source=fitted` 时，程序通过专用命名随机流 `reference_fit` 从接受目标抽取预热样本，并用期望最大化算法拟合参考高斯混合；它不直接读取解析目标的混合权重、均值和协方差。参考拟合样本、误差尺度点、盆地标准化点和误差校准点由相互独立的随机流产生。拟合后的参考责任度、盆地统计和全局提议在正式采样前冻结，参数与拟合信息保存在 `reference_mixture.json`。`reference.source=analytic` 会复制解析目标分量，只能作为预言机消融。

## 公平随机流

初始化、目标校准、误差场、路由、局部噪声、全局提议、接受判断和原始空间弗雷歇距离基准使用独立命名随机流。每个方法重新从相同命名种子开始，因此共享初态，并最大限度共享可比较的随机数。

## 诊断

原始空间弗雷歇距离每个检查点只使用各并行链的当前状态。秩归一化折叠分裂 $\(\widehat R\)$ 同时覆盖坐标、能量、责任度与硬模态指示量。硬模态指示量链内恒定但链间不同时返回无穷大。单模态初始化的多模态实验不会被声明为全局收敛；其他初始化还必须满足预注册的 JS 散度与最小模态占用比门槛。跨模态事件在固定 `crossing_stride` 网格上检查，分别保存首次进入成本、确认成本及每条链自身的删失成本。

## W&B 与本地记录

每个方法创建一条独立的 Weights & Biases（W&B）运行，并以每条链等效梯度成本作为主要步轴。W&B 初始化失败且 `wandb.strict=false` 时，异常写入 `wandb_error.txt`，采样仍继续写入本地 JSONL/CSV；`strict=true` 时初始化异常直接终止。CPU 任务可在启动命令前设置 `WANDB_X_DISABLE_STATS=true`，等价于 W&B 内部的 `Settings.x_disable_stats=true`，仅关闭主机系统指标采集，不影响显式调用 `run.log` 的实验指标。该内部设置具有版本敏感性。

本地输出目录由实验名和种子确定。写入器以覆盖方式打开 `metrics.jsonl`，其他同名文件也会重写，但程序既不清空目录，也不从旧文件恢复；所以同一路径重跑可能混合残留图件或 W&B 目录，不应视为断点续跑。正式运行应更换 `output.experiment_name`、`seed` 或 `output.root`。

## 假设

1. 合成主实验默认从独立预热样本拟合冻结参考盆地混合与全局提议中心；直接复用解析目标分量仅用于 `reference.source=analytic` 预言机消融。
2. $\(h_0,h_{\max},h_{\rm oper}\)$ 由配置预注册，不在实验样本上追逐接受率。
3. 成本权重是设备相关参数；默认值仅用于完成可运行流程。
4. 当前代码不实现状态相关核路由、持续自适应、学习接受能量或密度不可计算的扩散独立提议。
